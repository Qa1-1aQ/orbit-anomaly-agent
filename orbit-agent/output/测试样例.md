# 测试样例（端到端）

本样例演示一次完整、可复现的「轨道抬升」任务，按 **输入 → 模拟 → 输出 → 总结** 四段记录。本项目为确定性求解，无随机边界 / 失败分支，故以单一端到端样例作为标准可复现证据（不区分成功 / 边界 / 失败分类）。

## 输入

自然语言指令（提交 AGH 后由 Agnes 模型解析并调用工具）：

> 检测到卫星轨道异常：请用 run_scenario_tool 规划并执行「轨道抬升」任务，把轨道平均高度抬高约 40 km，随后用 verify_tool 验证入轨精度，并报告 Δv 与燃料消耗。

工具输入参数（由模型解析后传入）：

- `tle`：固定 ISS 快照（NORAD 25544，平均高度 426.558 km）
- `scenario`：`raise`
- `target_altitude_km`：466.558（= 426.558 + 40）
- `initial_fuel_kg`：50.0

## 模拟（工具调用链路）

1. `get_tle` → 返回固定 ISS 快照，`source` 标注 Celestrak 历史基线
2. `get_state` → 状态与轨道根数（a = 6804.7 km，e = 0.0011，i = 51.65°，周期 93.1 min）
3. `plan_maneuver_tool` → 单脉冲顺行 Δv = 22.307 m/s
4. `apply_maneuver_tool` → 施加脉冲，半长轴 a 变为 6844.7 km
5. `verify_tool` → 目标 466.558 / 实际 466.558 km，误差 0.00 km，燃料 3.777 kg

## 输出（关键数值）

- 抬升后平均高度：**466.558 km**（目标 466.558，误差 0.00 km）
- 标称单脉冲 Δv：**22.307 m/s**
- 燃料消耗：**3.777 kg**（剩余 46.223 kg）
- 验证判定：**PASS**

## 总结

在固定 ISS 基线（426.558 km）上，单脉冲顺行机动即可将平均高度精确抬升 40 km 至 466.558 km，Δv 22.307 m/s、燃料 3.777 kg，入轨精度误差为 0。所有数值可由活力公式独立复算（相对误差 < 0.001%），是「输入 → 模拟 → 输出」的标准可复现样例，评委可重复运行 `run_scenario_tool(scenario="raise")` 复现。
